Дан пофамильный список сотрудников IT-компании с указанием дней, проведенных ими в командировках за последние 2 года, и одной из должности: программист, аналитик, менеджер,
тестировщик и скрам-мастер. Для каждой должности определить среднее количество дней,
проведенных сотрудниками с такой должностью, в командировках, и вывести фамилии
сотрудников, находившихся в командировках дольше среднего. Изначально используется массив структур.
